# WinPrintServer 客户端连接指南

本文档说明如何从其他电脑连接到运行 WinPrintServer 的打印服务器。

---

## 前提条件

1. 打印服务器已启动（服务端 `http://<服务器IP>:8080` 可打开）
2. 客户端与服务器在同一局域网
3. 客户端已安装对应打印机驱动（如 Epson LQ-630K）
4. 防火墙已放行 TCP 9100（RAW）或 515（LPD）

---

## 方法一：Windows 标准 TCP/IP 端口（推荐）

这是最常用、兼容性最好的方式，适用于 Windows XP/7/10/11。

### 步骤

1. 打开 **控制面板 → 设备和打印机**（Windows 10/11 也可搜索「打印机」）
2. 点击 **「添加打印机」**
3. 系统搜索时选择 **「我所需的打印机未列出」**
4. 选择 **「添加本地打印机或网络打印机，手动设置」**
5. 选择 **「创建新端口」**
6. 端口类型选择 **「Standard TCP/IP Port」**
7. 填写：
   - **主机名或 IP 地址**：`192.168.1.100`（替换为服务器实际 IP）
   - **端口名**：自动填充，可改为 `9100`
   - **查询打印机并自动选择驱动**：取消勾选
8. 点击下一步，等待端口创建完成
9. **安装打印机驱动**：
   - 厂商选 `Epson`
   - 打印机选 `LQ-630K`（或您的实际型号）
   - 若列表中没有，点击「从磁盘安装」
10. 命名打印机（如 `LQ-630K-网络`）
11. 是否共享：选 **「不共享」**（网络共享已由服务器提供）
12. 完成后打印测试页

### 验证

- 打印测试页成功 → 连接正常
- 若失败，检查：
  - 服务器 IP 是否正确
  - 服务器端 8080 状态页是否显示「运行中」
  - 防火墙是否放行 9100

## 方法二：Windows LPR 端口

适用于需要 LPD 协议的环境。

### 前置：启用 Windows LPR 功能

**Windows 10/11：**
1. 设置 → 应用 → 可选功能（或「启用或关闭 Windows 功能」）
2. 勾选 **「打印和文件服务」→「LPD 打印服务」** 和 **「LPR 端口监视器」**
3. 重启电脑

**Windows 7：**
1. 控制面板 → 程序和功能 → 打开或关闭 Windows 功能
2. 勾选 **「打印和文件服务」→「LPD 打印服务」** 和 **「LPR 端口监视器」**

### 服务器端配置

确保 `config.ini` 中：
```ini
enable_lpd = true
```
并重启服务。

### 客户端步骤

1. 添加打印机 → 添加本地打印机 → 创建新端口
2. 端口类型选 **「LPR Port」**
3. 填写：
   - 提供 LPD 支持的服务器的名称或 IP 地址：`192.168.1.100`
   - 服务器上的打印机或打印队列名称：`lp`（任意名称）
4. 安装驱动，完成

## 方法三：直接端口打印（测试用）

适合快速测试，不适合日常使用：

```bat
:: 发送文本到打印机
echo Hello Printer > \\192.168.1.100\printer

:: 或使用 copy 命令
copy test.txt \\\\192.168.1.100\\9100
```

更准确的测试方式：

```bat
:: PowerShell 测试 9100 端口
Test-NetConnection -ComputerName 192.168.1.100 -Port 9100
```

## 方法四：Linux / macOS（CUPS）

### 使用 RAW (socket://)

```bash
# 安装打印机
lpadmin -p LQ630K-NET -E \
  -v socket://192.168.1.100:9100 \
  -m lq630k.ppd

# 或使用通用驱动
lpadmin -p LQ630K-NET -E \
  -v socket://192.168.1.100:9100 \
  -m drv:///sample.drv/generic.ppd

# 设置为默认
lpoptions -d LQ630K-NET

# 测试打印
echo "Test Print" | lp -d LQ630K-NET
```

### 使用 LPD

```bash
lpadmin -p LQ630K-NET -E -v lpd://192.168.1.100/lp
```

## 方法五：在开票/ERP 软件中配置

许多财务软件（如金税、用友、金蝶）允许自定义打印机端口：

1. 在软件中选择打印机为已添加的网络打印机
2. 或直接指定端口为 `\\192.168.1.100\9100`
3. 部分老软件支持指定 `LPT1`，可用 `net use` 映射：

```bat
net use LPT1 \\192.168.1.100\9100 /persistent:yes
```

## 防火墙配置

### 服务端（打印服务器）

以管理员身份运行：

```bat
:: 放行 RAW 9100
netsh advfirewall firewall add rule name="WinPrintServer RAW 9100" dir=in action=allow protocol=TCP localport=9100

:: 放行 LPD 515
netsh advfirewall firewall add rule name="WinPrintServer LPD 515" dir=in action=allow protocol=TCP localport=515

:: 放行 Web 8080
netsh advfirewall firewall add rule name="WinPrintServer Web 8080" dir=in action=allow protocol=TCP localport=8080
```

### 客户端

通常无需额外配置。若无法连接，临时关闭防火墙测试。

## 故障排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 添加打印机找不到 | 服务器未启动 | 启动服务，打开 8080 确认 |
| 连接超时 | 防火墙/网段 | 放行 9100，检查网络 |
| 打印空白 | 驱动不匹配 | 安装正确型号驱动 |
| 乱码 | 驱动/数据格式 | 确认使用 ESC/P 驱动 |
| 打印任务卡住 | 服务端打印机假脱机 | 重启 Print Spooler 服务 |
| 权限拒绝 | IP 限制 | 检查 config.ini 的 allowed_ips |

### 查看服务端日志

```
logs/print_server.log
```

关注 `打印失败`、`任务失败` 相关记录。

## 端口说明

| 端口 | 协议 | 用途 | 是否必须 |
|------|------|------|----------|
| 9100 | TCP RAW | 打印数据 | 是（推荐） |
| 515 | TCP LPD | LPR 打印 | 可选 |
| 8080 | TCP HTTP | 状态管理页 | 可选 |
